# Synapse NanoCPU

Synapse NanoCPU is an independent research project exploring an attractor-based solver built from constrained dynamic states.

The public showcase replays one real scenario generated by the local NanoCPU engine and presents its convergence visually through particles, density, constraints, and compact metrics.

This project is distinct from Synapse Corp product work and is intended to become part of a future Synapse Research Foundation initiative.

## Open the Visual Demo

Open the public showcase here: [https://oliver-66.github.io/NanoCPU/](https://oliver-66.github.io/NanoCPU/)

You can also launch `index.html` through a local static server or publish the contents of `public/` to GitHub Pages.
